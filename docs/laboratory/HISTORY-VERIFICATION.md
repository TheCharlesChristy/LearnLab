# Great Fire history pilot: verification and walkthrough

29 September 2026. Draft pack `great-fire-investigation` version 2 contains four planned and authored episodes, 12 reachable scenes, four source desks, four fresh bounded source-method checks and one final open case conference. It was created through the existing intake → plan → scaffold → research record → validate → stage authoring run at `authoring/runs/great-fire-investigation/`. The source and design ledger is [HISTORY-RESEARCH.md](HISTORY-RESEARCH.md).

The new registered `evidence-board@0.1.0` lets learners open evidence in any order, pin inspected cards, save a written claim, and self-review against an authored rubric. Its timeline dates the **record**, while its optional original schematic map indexes broad places. A card is labelled a paraphrase and links to the archival or museum record; no historical quotation or source image is copied. Free text is recorded locally and **never graded as mastery**. The independent checks ask bounded questions about what a source can establish; they do not score the learner's interpretation of the fire.

These runs verify controls and source display, not historical learning or human enjoyment. The scripted sample claims are intentionally **not** certified as good history. A human should assess a real learner's final case against the four prompts in `case-conference/conference`, including whether it uses independent records, distinguishes ignition from spread, rejects unsupported accusations, and identifies limits. The owner walkthrough and resulting revisions are pending; do not mark the parent goal complete before that feedback.

Local walkthrough after checking out this PR stack: build with `VITE_EXPERIENCE_RUNTIME_V2=true npm run build`, then run `./node_modules/.bin/vite preview --host 127.0.0.1`. Open `/#/laboratory/great-fire-investigation/first-report`; the map also offers all episodes as advisory progress. Try one source desk without following the timeline order, pin competing records, make a claim, inspect its rubric, use Help once, then visit `fire-map` and `case-conference`. Download the pack before testing offline. The circuits pilot remains at `/#/laboratory/research-station` in the same build. The owner can report where curiosity rose or fell, what felt like paperwork, where choices felt artificial, and whether the final claim felt genuinely argued; that report is a required revision input.
